# Правила сообщества BULL

[English](CODE_OF_CONDUCT.md) · Русский

## Стандарт общения

Мы приветствуем технические разногласия, строгую критику и русско-/англоязычные
предложения. Обсуждайте идеи, данные и ограничения, а не личные качества людей.

Хорошее участие — конкретные воспроизводимые примеры, честное обозначение
неопределённости, конструктивные исправления, уважение к опыту, языку и
оборудованию других участников, защита приватных данных.

Недопустимы травля, дискриминация, угрозы, публикация чужих приватных сведений,
систематический срыв обсуждений, spam и личные нападки.

## Область и меры

Правила действуют в Issues, Discussions, PR и других пространствах проекта.
Maintainers могут редактировать, скрывать или удалять сообщения и временно
либо постоянно ограничивать участие для защиты сообщества.

Используйте встроенный GitHub **Report content** для жалоб на оскорбления
или преследование. Не публикуйте личные данные в Issue. Для уязвимостей действует
отдельная [политика безопасности](SECURITY.md).

## Источник правил

Это правила самого проекта, основанные на общих принципах open source.
Они распространяются вместе с репозиторием по MIT; проект не заявляет
формальной сертификации по стороннему кодексу.
