# Поддержка BULL

[English](SUPPORT.md) · Русский

## Установка и вопросы

Начните с [установки](Docs/ru/INSTALLATION.md),
[подключений](Docs/ru/CONNECTIONS.md) и [руководства](Docs/ru/USER_GUIDE.md).
Для вопросов и методики используйте
[Discussions](https://github.com/MrChronon/bull/discussions), если они включены.
Поиск по существующим обсуждениям часто помогает быстрее.

## Воспроизводимый дефект

Откройте подходящую [форму Issue](https://github.com/MrChronon/bull/issues/new/choose).
Укажите версию, компонент, минимальные шаги и ожидаемый/фактический результат.
Для оценки тестов приложите ID/версию набора, задания и scorer. Для запуска —
Windows, Python, backend и способ установки без личных путей.

Проверьте **Дополнительно → Диагностика программы**: доступны базовые проверки
и полная регрессия. API-диагностика не генерирует ответы. Лог сохраняется локально;
не загружайте `client_debug.log` целиком без проверки.

## Приватность и безопасность

Не публикуйте ключи, токены, connection store, адреса, имена пользователей,
личные пути, приватные prompts/ответы или необработанные логи. Достаточно
минимального обезличенного фрагмента. Обычный raw JSON не является share-safe.

Для уязвимостей используйте [непубличный порядок сообщения](SECURITY.md),
не обычный Issue. Не проверяйте чужие системы без разрешения.

## Границы поддержки

Основная платформа — Windows 11. Linux/macOS пока не поддерживаются.
Установщик не разворачивает модели или сервер; их настройкой управляет владелец.
Проект не обещает время ответа или исправления. Не считаете автоматическую
проверку гарантией всех конфигураций терминала и удалённых серверов.
