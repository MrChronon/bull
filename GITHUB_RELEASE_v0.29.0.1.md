# BULL v0.29.0.1 — Pack Library

## English

Independent test packs, simpler setup and clearer comparisons for local LLMs.
**Stable release · 11 October 2026.** Designated as the latest stable version
by the project owner. Automated release checks pass; remaining manual checks
are listed under verification limits below.

### What's included

- Setup.exe asks for language and BULL Red/BULL Matrix, then packs/skip, full
  internal verification and connection/skip. BULL.exe appears only after completion.
- Six Home sections keep testing, chat, test settings, connection, appearance
  and additional tools separate. Home shows integrity/connection once.
- Four optional base ZIPs; batch numbers/`all`; explicit local/HTTPS pack import.
  Packs persist under the current user's library. A run uses one exact version/subset.
- Author Workshop builds data-only YAML/TXT sources with positive/negative fixtures.
- Complete private run snapshots, recoverable Windows checkpoint writes and resume.
- Basic/full diagnostics, honest empty-chat status, unsupported-THINK chat fallback,
  owned-process cleanup and independent CPU/RAM/GPU/VRAM value-or-N/A reporting.
- Language pack 1.0.1/scorer v2 and dedicated RU/EN native metrics/matched pairs.
  Historical 1.0.0/v1 and old results are not silently rescored.
- Full English/Russian guides, LLM author instructions and repository policies.
  GPU Lab, high contrast and server/all-in-one installer roles are removed.

### Install and upgrade

Download **BULL-v0.29.0.1-Bundle.zip** and its **.sha256.txt**, verify and extract
into a new folder; run **Setup.exe**. GitHub's automatic source archives are not
the tested install bundle. Windows 11, Python 3.10+ and PowerShell are required;
models/servers are installed separately. Python/dependency setup requires
confirmation. Native launchers are unsigned.

Packs survive upgrades outside the application directory. Privately back up
chats, results and connections; never overlay the old configured bundle.
See [installation](https://github.com/MrChronon/bull/blob/v0.29.0.1/Docs/en/INSTALLATION.md).

### Verification and limits

668/668 offline, 668/668 forced cp1251 and 18/18 essential startup checks,
manifest/privacy/ZIP checks and isolated fresh-install diagnostics. Every launch
reruns essential checks; Setup runs the full suite without model inference.
Counts are automated coverage, not proof of semantic quality or all environments.

Remaining manual validation: first/repeated Windows Terminal rendering and immediate
theme switching; folder deletion after normal exit; clean-machine dependency setup;
live chat, benchmark and interrupted resume on the intended local/SSH backends.
Stable designation does not mark these checks as completed.

This is a metadata-only promotion of the published v0.29.0.1 build. The tag,
ZIP and checksum are unchanged; documents inside the archive retain the initial
pre-release wording. Current repository documentation reflects stable status.

Compare native and client-assisted results separately. Missing resources are
unknown, not zero. Language scores cover six constrained tasks, not general
linguistic competence. Executable engine checks/chat tools are not an OS sandbox.
Linux/macOS, marketplace and arbitrary pack-report plug-ins are not shipped.
See [results](https://github.com/MrChronon/bull/blob/v0.29.0.1/Docs/en/RESULTS.md),
[acceptance](https://github.com/MrChronon/bull/blob/main/Docs/RELEASE_READINESS.md)
and [roadmap](https://github.com/MrChronon/bull/blob/v0.29.0.1/Docs/en/ROADMAP.md).

### Установка и обновление

Скачайте ZIP и **.sha256.txt**, проверьте сумму, распакуйте в новую папку и
запустите **Setup.exe**. Автоматический Source code не заменяет проверенный ZIP.
Нужны Windows 11, Python 3.10+ и PowerShell; модели/сервер — отдельно.
Установка Python/зависимостей требует подтверждения. Launchers не подписаны.

Наборы сохраняются вне приложения. Чаты, результаты и подключения сохраните
приватно; не накладывайте старую настроенную папку поверх новой.
См. [установку](https://github.com/MrChronon/bull/blob/v0.29.0.1/Docs/ru/INSTALLATION.md).

### Проверки и ограничения

668/668 offline, 668/668 cp1251, 18/18 startup, manifest/privacy/ZIP и полная
диагностика отдельной свежей установки. Startup повторяется при каждом запуске;
Setup выполняет полную регрессию без запросов к моделям. Это покрытие автотестов,
не доказательство смыслового качества или поддержки всех окружений.

Ручная валидация ещё открыта: первое/повторное отображение Windows Terminal,
мгновенная смена темы, удаление папки после штатного выхода, установка зависимостей
на чистой машине и live chat/benchmark/resume на целевых local/SSH backends.
Статус stable не означает, что эти проверки завершены.
