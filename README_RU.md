> **BULL — не облачный leaderboard.** Это открытая переносимая лаборатория для
> проверки качества, устойчивости, скорости и runtime-поведения локальных LLM без
> отправки prompts и ответов в сторонний сервис.

BULL работает с Ollama и совместимым HTTP-сервером llama.cpp. Он позволяет
общаться с моделями, сравнивать выбранные модели, восстанавливать прерванные
прогоны, анализировать результаты в терминале и автономном HTML и переносить
проверенный профиль в рабочий клиент.

## Зачем нужен BULL

**v0.29 Pack Library:** независимые ZIP-наборы сохраняются при обновлении
приложения. Один прогон использует точную версию и все либо выбранные задания.
Во время установки можно выбрать базовые наборы, свой ZIP или пропустить тесты.
[Мастерская автора](Docs/ru/AUTHOR_WORKSHOP.md) собирает редактируемые задания
в новую версию ZIP. [Библиотека](Docs/ru/PACK_LIBRARY_GUIDE.md) и
[инструкция для облачной LLM](Docs/ru/PACK_AUTHOR_LLM.md) объясняют весь путь.

| Проблема | Решение BULL |
| --- | --- |
| Recovery может скрыть слабый первый ответ | Native и Final system quality показываются отдельно |
| Среднее скрывает нестабильные seed | SD, min/max, worst seed и rank stability |
| Порядок влияет на скорость | Job-level counterbalanced план |
| Cold load смешивается с warm generation | Warm определяется по наблюдаемому load duration |
| Обрыв уничтожает долгий прогон | Atomic checkpoint и resume только незавершённой работы |
| Общие тесты не отражают работу пользователя | Собственные `.txt` и строгие `.yaml` задачи |
| Таблица не отвечает «что выбрать» | Качество, Скорость, Баланс, Мало памяти и свои веса |
| Один общий балл скрывает разницу языков | Отдельные русские, английские и парные bilingual-прогоны |

Для обычных наборов BULL показывает измеряемый топ-3 по Native quality, warm speed,
наблюдаемому пику VRAM и балансу. Эти места отделены от рекомендаций с
quality/TASK gate. В автономном HTML есть числовые диаграммы качества/скорости и
TASK/времени, ресурсы, heatmap тестов, происхождение параметров и краткие
описания тестов. Ни один из этих выводов не является универсальным рейтингом.

В v0.29.0.1 доступны отдельные русские и английские наборы, а также парный
bilingual-режим для одной и той же смысловой задачи. Это позволяет сравнивать
не только качество, но и скорость модели на каждом языке отдельно.
Языковой отчёт отдельно показывает соблюдение языка, чистоту письменности,
Native-время и разности точных RU/EN-пар, без общего победителя. Шесть задач
не доказывают общую языковую компетентность. CPU/RAM/GPU/VRAM относятся ко всему
узлу модели; недоступные показатели выводятся как `N/A`, не ноль.

## Быстрый старт

Требуются Windows 11, Python 3.10+ и PowerShell. Для чата и нового прогона
нужен отдельно установленный сервер Ollama/llama.cpp с моделью. Без него доступны
настройки, справка и сохранённые отчёты. Setup предлагает установку Python и
библиотек проверки только с подтверждением. Launchers не подписаны издателем.

1. Получите `BULL-v0.29.0.1-Bundle.zip` и `BULL-v0.29.0.1-Bundle.sha256.txt`.
   После публикации они доступны в [релизе этой версии](https://github.com/MrChronon/bull/releases/tag/v0.29.0.1).
   Автоматический архив GitHub «Source code» не заменяет проверенный установочный ZIP.
2. Проверьте checksum и распакуйте архив в новую папку.
3. Запустите `Setup.exe` со значком установки (`Setup.cmd` — запасной вход).
4. Выберите язык, затем **BULL Red** или **BULL Matrix**. Установите стандартные наборы, импортируйте ZIP
   по HTTPS-ссылке или из файла, либо пропустите.
5. Дождитесь полной внутренней регрессии. Настройте существующее соединение
   с LLM или пропустите этот шаг.
6. Выберите запуск BULL или выход из установщика.
7. Откройте **Тестирование моделей → Сравнить по набору тестов**, выберите версию,
   задания, модели и настройки. После прогона откройте рекомендуемый HTML.

Приложение открывает меню без работающей Ollama: настройки, справка и сохранённые
отчёты доступны offline. Для чата и нового benchmark нужна выбранная работающая связь.
До завершения Setup в корне нет `BULL.exe`; он появляется после полной проверки
и настройки/пропуска соединения. SHA-256, безопасное обновление и удаление описаны
в [руководстве установки](Docs/ru/INSTALLATION.md). Не накладывайте старую настроенную
папку поверх новой: наборы хранятся отдельно, а чаты, результаты и подключения
нужно сохранить осознанной приватной копией.

## Локально и удалённо

- **Локально:** BULL и модели работают на одном Windows-компьютере.
- **Удалённо:** BULL использует pinned SSH tunnel к отдельно настроенному узлу.
Установщик настраивает только клиент BULL, без развёртывания сервера.
Главная: тестирование, чат, настройки тестов, соединения и программы.
Пункт 6 «Дополнительно»: состояние сессии, диагностика, справка и Agent Benchmark
— без дополнительного уровня меню.
При каждом запуске заново проверяются целостность, связь и наличие наборов;
готовность отмечается зелёным, отсутствие настройки — предупреждением.
На главной показаны только целостность и связь; статус и просмотр наборов
находятся в тестировании и настройках тестов.
Обычный запуск — `BULL.exe` или созданный ярлык. Смена темы обновляет значки
своих ярлыков. Доступны только BULL Red и BULL Matrix.

Если `ssh bull-home` уже работает по ключу, выберите **Настройки соединения программы → Новый сервер
по SSH-алиасу** и введите `bull-home`. Не открывайте Ollama `11434` или llama.cpp
`8080` напрямую в Интернет. Подробности: [подключения](Docs/ru/CONNECTIONS.md).

## Результаты

Benchmark может создать raw JSON/CSV, checkpoint, summary, tested profiles,
private/share-safe evidence и автономный HTML. Provenance содержит hashes prompt,
pack, scorer и verifier, а также раздельные launch/effective fingerprints.

Релиз проверяется suite из **668** offline-проверок, privacy audit,
сверку manifest и полную проверку содержимого ZIP. В поставке используются только
идентификаторы и пути BULL; локальные данные и старые дубли splash-файлов исключены.

В локальном follow-up от 10 октября реализованы Setup без корневого `BULL.exe`
до установки, отдельный просмотр наборов, выбор полной диагностики, исправления
завершения собственных процессов и явный N/A для четырёх датчиков. GPU Lab удалён.
Набор языка 1.0.1/scorer v2 штрафует чужую письменность; RU/EN-отчёт разделяет
языки и точные пары без общего победителя. Prompts/эталоны и старые scores сохранены.
См. [руководство результатов](Docs/ru/RESULTS.md) и
[roadmap](Docs/BULL_TRANSITION_ROADMAP.md): live-терминал, освобождение папки
и model inference ещё требуют приёмки. По решению владельца v0.29.0.1 — stable;
незакрытые ручные проверки перечислены отдельно.
Перевод в stable меняет только метаданные релиза и актуальную документацию.
ZIP, checksum и tag сохраняют исходный проверенный snapshot; документы внутри
архива сохраняют первоначальную формулировку pre-release. Документация в `main`
отражает последующий статус stable. Программа и наборы не изменены.

```powershell
.\Run-Tests.ps1
.\Test-Public-Release.ps1 -AuditReleaseCandidatesOnly
.\Build-Release.ps1
```

## Безопасность

Модели не входят в bundle. Выполнение сгенерированного кода не является
OS-песочницей. Публичный релиз исключает `Chats`, `Runtime`, `Benchmarks`,
`Exports`, `Workspace`, ключи, endpoints и логи. Перед публикацией результатов
прочитайте [модель безопасности](Docs/ru/SECURITY.md).
