# BULL Language Comparison 1.0.1

This candidate pack separates Russian and English prompt tracks. Each bilingual pair has the same task intent, structured result contract, context budget, and output budget. Compare the recorded native score, task completion, warm throughput, and wall time by language; do not combine the tracks into one model score.

Scorer revision 2 penalizes foreign-script insertions in prose; JSON keys are excluded. Prompts and reference answers are unchanged from 1.0.0. These deterministic checks are not a comprehensive semantic evaluation. Existing installed 1.0.0 packs and results are never rewritten.

The pack contains no executable code. Its scorer ID is resolved by BULL's engine-owned allowlist.
