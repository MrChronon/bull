# Support

## Questions and setup help

Use [GitHub Discussions](https://github.com/MrChronon/bull/discussions) for
installation questions, benchmark methodology, model-runtime setup and general
usage. Search existing conversations first. English and Russian are welcome.

## Bugs

Use the structured [Issue forms](https://github.com/MrChronon/bull/issues/new/choose)
for reproducible failures and benchmark defects. Include the BULL version,
component, environment and minimal reproduction.

## Security

Do not open a public Issue for a vulnerability that could expose credentials,
private endpoints or user data. Follow [the security policy](.github/SECURITY.md).

## Before sharing diagnostics

Never publish a full connection store, private key, token, public IP, username,
home path, raw private prompt, model response or unreviewed `client_debug.log`.
Share the smallest sanitized excerpt that demonstrates the problem.
