# Support

[English](SUPPORT.md) · [Русский](SUPPORT_RU.md)

## Questions and setup help

Use [GitHub Discussions](https://github.com/MrChronon/bull/discussions) for
installation questions, benchmark methodology, model-runtime setup and general
usage when Discussions is enabled. Search existing conversations first.
English and Russian are welcome. Start with [installation](Docs/en/INSTALLATION.md),
[connections](Docs/en/CONNECTIONS.md) and the [user guide](Docs/en/USER_GUIDE.md).

## Bugs

Use the structured [Issue forms](https://github.com/MrChronon/bull/issues/new/choose)
for reproducible failures and benchmark defects. Include the BULL version,
component, environment and minimal reproduction.
Include pack/case/scorer identity for scoring problems. **Additional → Diagnostics**
offers basic checks or full regression; API diagnostics do not generate model answers.

## Security

Do not open a public Issue for a vulnerability that could expose credentials,
private endpoints or user data. Follow [the security policy](SECURITY.md).

## Before sharing diagnostics

Never publish a full connection store, private key, token, public IP, username,
home path, raw private prompt, model response or unreviewed `client_debug.log`.
Share the smallest sanitized excerpt that demonstrates the problem.

## Support boundaries

The primary platform is Windows 11; Linux/macOS are not supported yet. Setup
does not provision models or servers. No response/fix-time commitment is offered.
Automated coverage does not certify every Terminal or remote-server configuration.
