# Вклад в BULL

Спасибо за желание улучшить BULL — Benchmark Lab. Сначала создайте Issue: для ошибки используйте шаблон bug report, для новой идеи — feature request. Так обсуждение останется воспроизводимым и не потеряется между версиями.

## Перед отправкой изменения

1. Не добавляйте `Runtime`, `Chats`, `Benchmarks`, `Exports`, `Workspace`, модели, ключи, токены, частные адреса и персональные пути.
2. Не меняйте benchmark prompt, scorer и runtime pipeline в одном pull request.
3. Сохраняйте совместимость небольшими изменениями; baseline `v17.3.2` не переписывается.
4. Добавьте или обновите regression-тест для изменяемого поведения.
5. Запустите `Run-Tests.ps1` на Windows PowerShell и укажите результат в pull request.
6. При изменении релизного поведения обновите `Docs/USER_GUIDE.md` и `Docs/AI_CONTEXT.yaml`.

Не публикуйте в Issue полный `client_debug.log`, connection store или checkpoint без проверки. Сначала удалите имена пользователей, адреса, пути, промпты, ответы моделей и другие чувствительные данные.

## Область pull request

Предпочтителен один проверяемый смысловой шаг. В описании укажите проблему, выбранное решение, риски, результаты тестов и ручные проверки. Изменение benchmark должно отдельно объяснять совместимость исторических результатов.

## Лицензирование

Проект распространяется по лицензии MIT. Отправляя pull request, участник подтверждает, что имеет право передать свой вклад проекту на условиях MIT. Код, данные и benchmark packs из внешних источников должны сопровождаться совместимой лицензией и явным provenance.
