# BULL historical v0.21.0.0 — changelog

26 сентября 2026 года. Предыдущий релиз v0.20.0.0 сохранён без изменений.
Замороженная baseline проекта: v17.3.2.

## Новое: экспериментальная GPU Lab

- Выбор реальных NVIDIA GPU по UUID: отдельно и комбинациями, Windows + Ollama.
- Изолированная Ollama на loopback, локально или через pinned SSH; без перезапуска рабочего backend.
- Windows Job Object, проверка PID слушателя, EOF/lease cleanup, серверный mutex.
- Сценарии генерации текста, кода без исполнения, длинного входа и своего промпта.
- Fresh-process/repeated-prompt пары, повторения с ротацией порядка, атомарный checkpoint.
- Разделены requested launch и observed placement; N/A не превращается в ноль,
  CPU-only/неподтверждённые/загрязнённые фоновой нагрузкой runs не входят в сравнение.
- Терминальные таблицы, offline HTML и CSV; mean/SD/min/max, TTFT и GPU-датчики.
- Windows process/API integration на синтетических executables, без реальной GPU-нагрузки.
- Startup cache включает Server/Tests PowerShell; public gate запрещает все `*.private.json`.
- BULL обсуждается как имя; переименование и миграция настроек не выполнялись.

## Сохранено: интерфейс v0.20.0.0

- task-based home и короткие вложенные меню, прямые /команды, единый /menu=/home;
- семантические цвета, текстовые статусы и компактный Matrix accent;
- Agent Benchmark внутри тестов, draft-конфигурация, явное подтверждение запуска;
- короткая Agent-сводка; подробности и HTML доступны отдельно;
- чтение результата подключения до возврата на главную.

## SSH

- пошаговый мастер без ручного составления connection JSON;
- получение публичного Ed25519 ключа только как непроверенного кандидата;
- независимый SHA256 fingerprint обязателен до сохранения;
- opt-in адресная книга вне версионной папки; private key bytes не читаются и не копируются;
- перенос из старого Runtime или ручного SSH-профиля, без импорта всего backend_settings;
- fail-closed при несовпадении сохранённого ID/ключа/endpoint;
- строгая проверка индексов выбора (0 и отрицательные числа не выбирают последний сервер).

## Проверки

PowerShell-скрипты сохраняют UTF-8 BOM для Windows PowerShell 5.1. ZIP формируется
явными manifest entries с разделителем /, включая dotfiles; результат не зависит
от того, какие разделители использует Compress-Archive на установленной версии PowerShell.

Добавлен Tests/ux_regression.py: навигация, отмена, SSH identity, перенос между билдами,
приватность ссылки на ключ, простые Agent defaults и различение видов неудачных проверок.
UI expectations существующих тестов обновлены для новой карты меню.
Контракты вычислений, prompt/scorer fixtures и транспортные тесты сохранены.

GPU Lab добавлена отдельными модулями. Генерация, скоринг, задачи Agent, checkpoint
и prompts существующих режимов не изменены. Новый hardware pipeline не выдаёт quality score.
