# Changelog v0.27.0.0

## Added

- Safe `UserTests` `.txt` and `.yaml` workflows.
- Deterministic `user_contract_v1` scorer for declared YAML criteria.
- Decision-support profiles and custom priority weights.
- Terminal quality/speed map and equivalent offline HTML section.
- In-application saved-result summary and export-path view.
- Regression suites for user tests and decision support.

## Changed

- Home, benchmark, connection, and post-run menus use progressive disclosure.
- Expert, server, Agent, and GPU actions are under More/Experimental.
- A compact BULL mark appears on each navigational page.
- English localization covers the new primary routes.
- Current launchers, installers, documentation, and packaging identify v0.27.

## Not changed

- Built-in benchmark prompts or scorers.
- Inference runtime and recovery pipeline.
- Historical artifact schemas.
- T5.2 Local System Matrix remains postponed.
