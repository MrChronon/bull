# BULL v0.22.0.0 — changelog

## Added

- public identity **BULL — Benchmark Lab**;
- vector mark, wordmark, light/mono variants, PNG sizes, Windows ICO, favicon and social preview;
- `Shared/bull_llm` public compatibility facade;
- strict read-only recognition of supported historical artifacts;
- migration guide and compatibility launchers with visible notices;
- offline tests for branding, aliases, facade identity and non-mutating readers.

## Changed

- current launchers, installer, shortcut, report title and release package use BULL;
- release manifest and ZIP root use `BULL-v0.22.0.0-Bundle`;
- human and LLM-facing documentation describes the BULL bridge.

## Intentionally unchanged

- all benchmark prompts;
- scorers and score semantics;
- model execution/recovery pipeline;
- legacy schema identifiers and versions;
- public local-only network defaults.
