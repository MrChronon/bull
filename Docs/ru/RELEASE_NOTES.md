# BULL v0.28.0.3 — Clear Choice

Этот релиз делает выбор среди установленных локальных моделей более надёжным.
Встроенные benchmark prompts, встроенные scorers и inference/recovery runtime
pipeline не изменялись.

## Основные изменения

- При равной utility показываются равноценные кандидаты, а не произвольно
  выбранное имя модели.
- Наблюдаемое среднее Native score и консервативная нижняя граница 95% CI имеют
  отдельные подписи.
- Неизвестная VRAM остаётся неизвестной; профиль **Мало памяти** недоступен без
  сопоставимых измерений.
- Новые YAML-задачи используют строгий `user_contract_v2`; старые v1-artifacts
  остаются читаемыми без тихого пересчёта.
- Добавлены три синтетических самодостаточных примера: извлечение, расчёт и
  деловой перевод.
- Проверенный startup gate теперь показывает отдельное нативное desktop-окно с
  versioned изображением BULL, наблюдаемым этапом и точным именем файла набора
  регрессии; оно закрывается до меню и не может изменить фон терминала. BULL
  Red — тема по умолчанию, зелёная альтернатива называется Matrix BULL.

Публичный bundle не содержит модели, чаты, benchmark results, runtime state,
частные подключения, ключи, tokens, endpoints и локальные логи.
