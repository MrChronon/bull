# BULL v0.28.0.7 — чистый публичный релиз

v0.28.0.7 объединяет возможности ветки v0.28 в проверенный публичный bundle.
Контракты бенчмарка сохранены, а результаты стали понятнее во время прогона,
в терминальной сводке и в автономном HTML-отчёте.

## Что нового

- Отдельные русские, английские и билингвальные треки позволяют сравнивать
  качество и скорость моделей для каждого языка.
- Терминал и HTML показывают топ-3, карты «качество ↔ скорость», heatmap тестов,
  диапазоны стабильности, ресурсы и простые пояснения показателей.
- После каждого завершённого теста выводится checkpoint с результатом,
  скоростью и доступной телеметрией CPU, RAM, GPU и VRAM.
- HTML-отчёт выделен как рекомендуемый способ изучить результат; JSON и CSV
  остаются доступными для воспроизводимого анализа.
- Параметры sampler из Ollama-профилей определяются до запуска и записываются
  отдельно, не ослабляя строгую проверку runtime-настроек.

## Целостность и приватность

- Полный offline regression проходит **401/401** проверок.
- Проверенный ZIP содержит **256** файлов под контролем manifest.
- Публичные имена, пути, launchers, schemas и документация используют только
  идентификаторы BULL; устаревшее название продукта не поставляется.
- Чаты, результаты тестов, runtime state, подключения, ключи, tokens, endpoints,
  личные пути и локальные логи исключены.
- Рядом с архивом опубликован SHA-256 для независимой проверки.
