# BULL v0.27.0.1 — Simple Experience

В v0.27 основной сценарий построен вокруг задач пользователя: подключиться к
моделям, сравнить их, прочитать результат или открыть чат. Экспертные команды,
развёртывание сервера, Agent Lab и GPU Lab сохранены в дополнительных и
экспериментальных разделах.

## Основные изменения

- красное оформление публичного релиза: wordmark, сигнальная панель и social preview; locked master-логотип не меняется;
- главное меню из четырёх пунктов и понятные маршруты local/remote подключения;
- язык выбирается один раз, затем меняется в настройках;
- терминальные темы BULL, Matrix, Red и высокая контрастность;
- каноническая полноцветная голова быка и расшифровка названия на каждой странице;
- повторно используемые `.txt` и строгие `.yaml` задачи в `UserTests`;
- краткое сравнение прямо в приложении после прогона;
- прозрачные профили Качество, Скорость, Баланс, Мало памяти и собственные веса;
- относительная карта качества/скорости в терминале и HTML;
- явное разделение share-safe summary и приватных raw artifacts;
- локализованные сообщения восстановления без вывода исключений старого языка;
- атомарный checkpoint/resume с сохранением завершённых runs.

Native model quality и final system quality остаются раздельными. Recovery,
runtime и transport metrics не меняют native quality. Встроенные prompts, scorers
и inference pipeline не переписывались в рамках интерфейса Simple Experience.

Публичный bundle не содержит модели, чаты, результаты benchmark, runtime state,
частные подключения, ключи, tokens и локальные логи.
