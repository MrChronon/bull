# BULL v0.28.0.6 — Более ясные итоги benchmark

Релиз улучшает представление результатов. Встроенные benchmark prompts, scorers,
recovery и inference runtime не менялись.

## Главное

- Измеряемый топ-3 по Native quality, warm speed, наблюдаемому пику VRAM и
  балансу.
- Рекомендации отделены от мест: отчёт показывает quality/TASK gate и причину,
  по которой для профиля нет подходящей модели.
- После каждого сохранённого run появляется короткий предварительный итог
  только текущего теста.
- В live-строке доступны GPU/VRAM и, когда узел их предоставляет, агрегированные
  CPU/RAM.
- Автономный HTML-отчёт переработан в красном стиле BULL: диаграммы, ресурсы,
  рейтинг, описания тестов и происхождение параметров.

Перед выбором модели прочитайте раздел [«Результаты»](RESULTS.md).

Публичный bundle не содержит модели, чаты, benchmark results, runtime state,
частные подключения, ключи, tokens, endpoints и локальные логи.
