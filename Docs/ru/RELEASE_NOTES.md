# BULL v0.28.0.5 — Чистый запуск benchmark

Этот patch упрощает настройку benchmark и добавляет контекст ресурсов активного
узла. Встроенные benchmark prompts, встроенные scorers и inference/recovery
runtime pipeline не изменялись.

## Основные изменения

- Номера моделей можно вводить с пробелами после запятых, например `2, 4, 7`.
- Выбор источника sampling открывается на отдельном чистом экране после preset.
- В live-строке показываются агрегированные CPU и RAM рядом с GPU и VRAM, если
  эти измерения доступны на активном узле.
- После каждого сохранённого run выводится короткий checkpoint с результатом,
  скоростью и доступными ресурсами до окончания всего набора.

Публичный bundle не содержит модели, чаты, benchmark results, runtime state,
частные подключения, ключи, tokens, endpoints и локальные логи.
