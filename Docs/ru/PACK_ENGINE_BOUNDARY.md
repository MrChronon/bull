# PK1.2 — Engine Boundary

## Ответственность слоёв

| Слой | Назначение |
| --- | --- |
| Каталог движка | Списки разрешённых runner/scorer/verifier, валидированные задания и точное происхождение набора |
| Данные набора | Промпты, эталоны, ограничения, инструкции формата, настройки скореров и бюджеты генерации |
| Эталоны диагностики | Контракты регрессии и исторического аудита; не запасной каталог для прогона |
| Адаптер клиента | Одна явно выбранная установленная версия; свободные пользовательские задания — отдельный сценарий |

`Shared/bull_llm/evaluation/catalog.py` не импортирует клиент, транспорт или
содержимое тестов. Набор не может расширить список возможностей движка своими
декларациями. Пустой реестр допустим. Повторяющиеся ID заданий, в том числе между
версиями, отклоняются: клиент не выбирает и не перезаписывает их молча. Задания
для preview копируются глубоко, а не разделяют изменяемый объект набора.

## Сохранённые контракты

12 заданий CHAT Core и все прежние файлы/хеши этого набора не изменены.
Четыре остальных прежних задания находятся в `bull_extended_core@1.0.0`.
Для всех 16 заданий регрессия сравнивает хеши определения, итогового промпта,
эталона и исполнения. Дополнительно проверяются хеши 15 полных результатов
скореров на прежних эталонных ответах. Тексты, эталоны, алгоритмы оценивания и
бюджеты генерации здесь не пересматриваются.

Совместимый `builtin_benchmarks()` читает эталонный файл только для регрессии и
исторического аудита. `load_benchmarks()` не вызывает его и не заполняет им пустую
библиотеку. Выбор отсутствующего задания даёт `BENCHMARK_CASE_NOT_AVAILABLE`
до обращения к API модели.

Набор содержит только данные, но это не изолирует прежние проверки кода движка.
Retention/Python требуют разрешения на выполнение кода и одноразовой VM для
недоверенного вывода. Установка набора не может включить такое разрешение.

## Проверки и оставшиеся работы

PK1.2 gate: 439/439; PK1.3 gate: 465/465. Проверяются пустой и независимый каталоги, разрешения
движка, независимость диагностики, сохранённые сводки, исторический аудит,
конфликты ID и изоляция изменений preview. Сборщик CHAT Core читает замороженные
данные, не импортируя модуль клиента.

PK1.3 подключает `%LOCALAPPDATA%/BULL/BenchmarkPacks`, необязательную установку
базового/авторского ZIP, явный выбор версии и preview всего набора либо отдельных
тестов. Исходники базовой поставки и эталоны движка не заполняют рабочий каталог.
Прежние регрессионные тесты получают эталонный каталог явно.
См. [руководство библиотеки](PACK_LIBRARY_GUIDE.md). Веса исторических suite
остаются политикой совместимости. v0.29.0.1 использует один набор на прогон и
полные проверяемые приватные снимки в checkpoints/evidence. Новым снимкам не нужна
установленная копия для resume; подмена содержимого недопустима. Share-safe
содержит только разрешённые хеши и покрытие. PK1.5 первоначально прошёл 518
проверок; follow-up от 10 октября — 668/668, gold извлечения сохранён.
Текущие gates и открытая live-приёмка: [руководство разработки](DEVELOPMENT.md).
