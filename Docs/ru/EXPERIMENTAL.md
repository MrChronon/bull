# Экспериментальные функции

Экспериментальные возможности находятся в **Дополнительно → Экспериментальные
функции**. Они не нужны для обычного чата и сравнения моделей.

## Agent Benchmark

Agent Lab выполняет ограниченные многошаговые задачи с независимой проверкой.
Он фиксирует успех задания, verifier results, tool calls, повторы, длительность,
вмешательства и доступную telemetry. Успешный tool call не доказывает выполнения
задачи: authoritative результат даёт verifier.

Agent может создавать файлы и запускать код с правами пользователя. Используйте
disposable workspace или VM. Приватная конфигурация и полный trace находятся в
`Benchmarks/Agents` и требуют проверки перед публикацией. HTML-отчёт — результат
анализа, а не сертификат безопасности.

## GPU Lab

GPU Lab предназначена для экспериментов Windows + Ollama. Она сравнивает заданные
конфигурации GPU, включая одну карту и поддерживаемые комбинации. BULL сохраняет
наблюдаемую telemetry и использует unknown, а не ноль, если sensor недоступен.

Выбранная конфигурация задаёт намерение эксперимента; реальное размещение зависят
от Ollama, drivers, размера модели и ОС. Проверяйте effective GPU use по telemetry.
BULL завершает только принадлежащее ему дерево worker processes; другие задачи
на выбранных GPU пользователь останавливает самостоятельно.

Результаты имеют смысл, только если зафиксированы модель, quantization, context,
sampling, driver, температура, background load, power policy и порядок запусков.

## Расширенные настройки движка и сервера

Ручные пути Ollama/llama.cpp, развёртывание сервера, низкоуровневая диагностика
и compatibility commands сохранены для опытных пользователей. Они скрыты с
основного маршрута: обычному пользователю достаточно локальной Ollama,
сохранённого сервера или SSH-алиаса.
