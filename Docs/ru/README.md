# Документация BULL на русском

BULL — Benchmarking & Usage of Local Language Models — сравнивает локальные модели на том
оборудовании и через то подключение, где они будут использоваться.

Начните с [руководства пользователя](USER_GUIDE.md). Обычный маршрут:

1. пройти [установку](INSTALLATION.md) или открыть **Настройки соединения программы**;
2. открыть **Тестирование моделей**;
3. выбрать **Сравнить по набору тестов**, **Задача из UserTests** или **Мой промпт**;
4. прочитать краткий результат в BULL и при необходимости открыть HTML-отчёт.
