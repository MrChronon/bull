# Документация BULL на русском

BULL — Benchmarking & Usage of Local LLMs — сравнивает локальные модели на том
оборудовании и через то подключение, где они будут использоваться.

Начните с [руководства пользователя](USER_GUIDE.md). Обычный маршрут:

1. открыть **Подключение** и выбрать этот компьютер или сохранённый SSH-сервер;
2. открыть **Сравнить модели**;
3. запустить **Стандартное сравнение** или **Мои задачи и промпты**;
4. прочитать краткий результат в BULL и при необходимости открыть HTML-отчёт.
