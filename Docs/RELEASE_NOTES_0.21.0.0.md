# BULL historical v0.21.0.0 — экспериментальная GPU Lab

Дата: 26 сентября 2026 года.

## Новое: RTX 3060, P100 и совместная работа

**Тесты → 7**, либо `/gpu`: выберите карты, конфигурации, модели и сценарии.
Раздельные процессы Ollama с GPU UUID, проверка размещения процессов и GPU offload,
датчики каждой карты, таблицы и HTML, повторы и SD/min/max, восстановление после сбоя.
Рабочая Ollama не перезапускается, системные переменные и подключение не меняются.
Нагрузка требует явного подтверждения. Режим Windows + Ollama, локально или по SSH.
Это экспериментальный инструмент производительности, не оценка качества моделей.
Реальная пара RTX 3060/P100 и WAN ещё требуют smoke-прогона; CPU-only и
неподтверждённые GPU-измерения не выдаются за успешное сравнение.
Порядок действий и ограничения: `Docs/GPU_LAB.md`.

Ниже — сохранённые возможности предыдущей версии.

BULL — переносимое Windows-приложение для чата с Ollama/llama.cpp,
сравнения моделей и агентских coding-тестов. Модели работают локально или на
вашем сервере через SSH. В архиве нет моделей, личных подключений и ключей.

## Главное в этой версии

- Пять разделов главной: Чат, Тесты и результаты, Подключения, Настройки и помощь, Команды.
- Команду с / можно набрать прямо на главной. /menu и /home больше не открывают разные меню.
- Голубые пункты управления, светлый текст, зелёный успех, жёлтые предупреждения,
  красные ошибки. Цвет всегда дополнен подписью; темы яркости сохранены.
- Убраны повторяющиеся рамки, бинарная декорация и неработающая общая подсказка ?.
- Мастер SSH: адрес и порт → пользователь и ключ → проверка fingerprint → подтверждение.
  Локальная Ollama не нужна. Известный ключ сервера нельзя молча заменить.
- Подключения можно явно запомнить вне билда в личной папке Windows. После распаковки
  следующей версии достаточно выбрать сервер и подтвердить его использование.
  Ключ не копируется. Старые настройки переносятся из выбранной папки с предварительным просмотром.
- Agent Benchmark: выбор модели со стандартными параметрами, отдельные простые/расширенные
  настройки, краткий итог и полные показатели по запросу. Неудачная промежуточная проверка
  кода больше не выглядит как падение приложения.

## Как начать

1. Распакуйте ZIP в новую папку; проверьте SHA-256.
2. Запустите исторический launcher v0.21.0.0 (или installer для недостающих компонентов).
3. На главной выберите Подключения. Для локальных моделей — этот компьютер; для
   удалённых — добавить сервер по SSH. Требуется уже подготовленный SSH-сервер и ключ.
4. При первом переходе со старого билда: Подключения → Дополнительно → Перенести из старой версии.
5. Чат: 1 → открыть чат → модель. Тесты: 2 → нужный сценарий.
   Агентская задача: 2 → 5 → настройки → модель → S → запуск → 1.
6. Справочник команд: /help all. Подробная инструкция — Docs/UI_GUIDE.md и Docs/USER_GUIDE.md.

Мастер не устанавливает сервер, не меняет роутер и не добавляет публичный ключ в
authorized_keys. Инструкции подготовки: Docs/BACKEND_SETUP.md и Docs/REMOTE_ACCESS.md.
Не публикуйте Ollama 11434 или llama.cpp 8080 в Интернет.

## Совместимость и границы

Регрессионный набор: 305 проверок, включая 19 GPU-контрактов и Windows process/API integration. Сборка проверяет
Python compile, полный regression в UTF-8/cp1251, приватность, manifest и hash каждого ZIP entry.

Промпты, скореры, формулы метрик, Agent-задача/verifier, inference pipeline и параметры
генерации существующих режимов не менялись. Исправления устойчивости и безопасности v0.19.0.1 сохранены.
Старый незавершённый benchmark лучше закончить старым билдом; не обходите version guard
checkpoint. Agent MVP повторяет прерванную попытку с начала, не восстанавливает её середину.

Адресная книга: %LOCALAPPDATA%/BULL/connections. Это незашифрованные приватные
метаданные в профиле пользователя, а не секретный ключ. Не публикуйте её, Runtime,
Benchmarks, Chats или configuration.private.json. Храните приватный ключ вне удаляемых
папок билда. Свежий ZIP не выбирает сохранённый сервер автоматически.

Сохраняется известное ограничение: legacy исполняемые CODE-тесты и подтверждённый
пользователем Python tool чата не имеют OS sandbox. Для недоверенного кода нужна
одноразовая VM без секретов и сети. Agent fixture использует ограниченный интерпретатор.
Реальная WAN-связь, NAT и нагрузка моделей этой сборкой автоматически не проверялись.
