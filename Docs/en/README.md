# BULL documentation in English

BULL — Benchmarking & Usage of Local LLMs — compares local models on the
hardware and connection that will actually be used.

Start with the [user guide](USER_GUIDE.md). The usual route is:

1. choose **Connection** and select this computer or a saved SSH server;
2. choose **Compare models**;
3. run **Standard comparison** or **My tasks and prompts**;
4. read the concise result in BULL and open the HTML report when needed.
