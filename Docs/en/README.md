# BULL documentation in English

BULL — Benchmarking & Usage of Local Language Models — compares local models on the
hardware and connection that will actually be used.

Start with the [user guide](USER_GUIDE.md). The usual route is:

1. complete [installation](INSTALLATION.md) or open **Connection settings**;
2. choose **Model testing**;
3. choose **Compare a test pack**, **Task from UserTests** or **My prompt**;
4. read the concise result in BULL and open the HTML report when needed.
