# Follow-up corrections · 10 October 2026

Start the extracted bundle with **Setup.exe**. `BULL.exe` is not distributed in
the root: Setup creates it from a manifest-verified payload after regression and
connection setup/skip. Start the installed application or exit at the last step.

The home status strip contains integrity and connection only. Test availability
is shown in Test settings and Model testing. Their read-only browser lists pack
versions first, then their tasks. It does not change the current selection.

The terminal bull is emitted as 24 bounded, flushed rows before the wordmark.
The canonical 48×24 artwork is unchanged. Live Windows Terminal visual acceptance
is still required; no claim of screenshot-level validation is made.

Additional → Diagnostics offers basic checks or the same full regression as
Setup. GPU Lab, its command, module and worker have been removed. This does not
remove ordinary GPU/VRAM telemetry or existing user experiment results.

Empty sessions are not automatically saved and status does not invent an active
chat. Chat uses FAST for models known not to support THINK. An explicit unsupported
THINK HTTP 400 can trigger one chat-only retry without THINK (tools off only);
unrelated errors and benchmark contracts are not silently retried or changed.

Owned sampler/SSH processes are reaped, waited and their pipes closed at exit.
Terminal's launcher starts from a neutral directory so its shared host need not
hold the bundle directory. Separately running LLM servers are not stopped.
All possible folder locks are not proven resolved. A finite read-only probe on
the selected pinned inference host confirmed GPU/VRAM and CPU/RAM measurements
after quoting the OpenSSH `UserKnownHostsFile` value for paths with spaces.
Strict host-key verification remains enabled; no trust keys were changed.
Samplers now report missing GPU, VRAM, CPU and RAM separately rather than hiding
missing sensors. Optional missing GPU temperature/power no longer discards VRAM.

Author Workshop starter validation is fixed. Russian deletion copy now says
**корзина BULL** (the library's recoverable internal bin, not Windows Recycle Bin).
The library root resolves dynamically from the user's environment.

Language tracks select one installed compatible pack before model discovery.
Language pack **1.0.1**, scorer **v2**, penalizes other-script letters in prose;
JSON is excluded. Prompts, reference answers and generation budgets are frozen
from 1.0.0. Historical v1 remains supported and is retained as a hash-locked
public regression fixture. Existing user packs/results are never rewritten.
Both language ZIP revisions are included at their intended release paths.
Packaging fails if any mandatory file is filtered out of the manifest inventory.

Specialized RU/EN reports lead with separate track checks, language compliance,
script purity, native wall time, warm throughput, seed ranges and matched-pair
differences. No merged-language winner is assigned. Native and recovery remain
separate. Pairing requires equal recorded model/digest, pack/scorer revision,
seed/run and generation settings; ambiguous attempts are excluded. These six
tasks have limited semantic discrimination, and 100% is not proof of general
language competence. Historical v1 reports carry an explicit caveat.

Future pack-specific report templates should be engine-owned or declarative,
schema-validated profiles, not arbitrary pack-supplied HTML/JavaScript or code.
Semantic prompt/scorer redesign is a separate versioned change, not part of this fix.

Verified regression: **668/668**, no model inference. Release archive and startup
integration checks are separate gates. Post-benchmark menus clear on subsequent
draws and pause after opening reports/answers, preserving saved artifacts.
