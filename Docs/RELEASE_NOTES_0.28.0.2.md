# BULL v0.28.0.2 — Startup status and BULL Red

BULL v0.28.0.2 is a presentation and usability patch. Built-in benchmark prompts,
scorers, model-runtime options, recovery behaviour, and the separate
native/final quality metrics are unchanged.

## What changed

- The separate startup window now names the active verification suite instead
  of showing only a generic progress phase.
- **BULL Red** is the default terminal theme.
- **Matrix BULL** remains available as the green alternative under
  **More → Language and appearance**.
- Older saved BULL-brand appearance settings open in BULL Red automatically.

## Install

1. Verify and extract `BULL-v0.28.0.2-Bundle.zip`.
2. Run `Install-BULL-v0.28.0.2.cmd`.
3. Start `BULL-v0.28.0.2.cmd`.

The startup window is presentation only. If Tk or Windows GUI facilities are
not available, the mandatory offline verification still runs and BULL opens in
the terminal.
