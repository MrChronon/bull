# BULL v0.28.0.7 — Clean Release

This release is the audited public snapshot of the v0.28 benchmark experience.
Built-in benchmark prompts, scorers, recovery behavior, and the inference
runtime are unchanged.

- Russian, English, and bilingual benchmark tracks are separated.
- Live checkpoints include score, speed, and available CPU/RAM/GPU/VRAM data.
- Terminal and offline HTML reports include top-3 rankings, comparison maps,
  test heatmaps, stability, resources, and decision-oriented explanations.
- Ollama profile-owned sampler differences are recorded explicitly and no
  longer treated as forbidden runtime differences.
- Public regression: **401/401**.
- Audited public archive: **256 files**, with manifest and SHA-256 verification.
- Private chats, results, settings, connections, secrets, endpoints, paths, and
  logs are excluded; public product identifiers are BULL-only.
