BULL v0.28.0.1 — Benchmarking & Usage of Local LLMs
====================================================

ENGLISH
-------

Simple Experience keeps the primary route focused on model comparison, chat,
connection, and additional features. After a run, the concise comparison,
decision profiles, and quality/speed map are available in the terminal and the
offline HTML report.

Put reusable tasks in UserTests. A .txt prompt receives runtime measurements and
manual review without a fabricated quality score. A strict .yaml task uses only
declared deterministic criteria.

Install:       Install-BULL-v0.28.0.1.cmd
Application:   BULL-v0.28.0.1.cmd
Benchmark Lab: BULL-Benchmark-Lab-v0.28.0.1.cmd
Agent Lab:     BULL-Agent-Lab-v0.28.0.1.cmd

Documentation: Docs\en\README.md

РУССКИЙ
-------

Simple Experience оставляет на основном маршруте сравнение моделей, чат,
подключение и дополнительные функции. После прогона краткая сводка, профили
выбора и карта качества/скорости доступны в терминале и автономном HTML.

Повторно используемые задачи помещаются в UserTests. Для .txt измеряется runtime,
но не создаётся выдуманный quality score. Строгий .yaml использует только явно
заданные детерминированные критерии.
