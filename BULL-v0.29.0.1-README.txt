BULL v0.29.0.1 — Benchmarking & Usage of Local Language Models
====================================================

ENGLISH
-------

Pack Library keeps the primary route focused on model comparison, chat,
test settings, connection settings, and program settings. Home section 6,
Additional, contains diagnostics, help, session status and experimental tools.
After a run, the concise comparison,
decision profiles, and quality/speed map are available in the terminal and the
offline HTML report.

Setup: language, BULL Red / BULL Matrix, base/user ZIP (local or HTTPS) or skip, full regression,
existing connection or skip, then launch or exit. One exact pack per comparison,
all or selected tasks. Storage: %LOCALAPPDATA%\BULL\BenchmarkPacks
Author Workshop builds editable sources; private snapshots preserve resume.
Loose tasks remain in UserTests. A .txt prompt receives runtime measurements and
manual review without a fabricated quality score. A strict .yaml task uses only
declared deterministic criteria.

Install:       Setup.exe (Setup.cmd fallback); language, then BULL Red / BULL Matrix
Application:   BULL.exe (BULL-v0.29.0.1.cmd compatibility entrypoint)
Benchmark Lab: BULL-Benchmark-Lab-v0.29.0.1.cmd
Agent Lab:     BULL-Agent-Lab-v0.29.0.1.cmd

Documentation: Docs\en\README.md

BULL.exe appears only after Setup completes; start with Setup.exe in a fresh ZIP.
Stable edition by owner designation, 11 October 2026; manual acceptance remains open.
Published tag/ZIP/checksum are unchanged; current repository documents record promotion.
Current release gates/manual acceptance: Docs\RELEASE_READINESS.md

РУССКИЙ
-------

Pack Library оставляет на основном маршруте сравнение моделей, чат,
настройки тестов, соединения и программы. Пункт 6 «Дополнительно» содержит
диагностику, справку, состояние сессии и экспериментальные инструменты.
После прогона краткая сводка, профили
выбора и карта качества/скорости доступны в терминале и автономном HTML.

Установка: язык, BULL Red / BULL Matrix, базовый/авторский ZIP (файл/HTTPS) или пропуск,
полная регрессия, существующее соединение или пропуск, запуск или выход. Один набор и точная версия
на прогон, все либо выбранные тесты. Мастерская собирает редактируемые исходники,
а приватный снимок сохраняет задания для resume после удаления набора.
Общая папка: %LOCALAPPDATA%\BULL\BenchmarkPacks
Свободные задачи остаются в UserTests. Для .txt измеряется runtime,
но не создаётся выдуманный quality score. Строгий .yaml использует только явно
заданные детерминированные критерии.

Установка:     Setup.exe (запасной вход Setup.cmd); язык, затем BULL Red / BULL Matrix
Приложение:    BULL.exe (совместимый вход BULL-v0.29.0.1.cmd)
Benchmark Lab: BULL-Benchmark-Lab-v0.29.0.1.cmd
Agent Lab:     BULL-Agent-Lab-v0.29.0.1.cmd

Документация: Docs\ru\README.md

BULL.exe появляется только после завершения Setup; в новом ZIP начинайте с Setup.exe.
Стабильный релиз по решению владельца, 11 октября 2026; ручная приёмка ещё открыта.
Опубликованные tag/ZIP/checksum неизменны; текущие документы отражают перевод в stable.
Проверки и незакрытая ручная приёмка: Docs\RELEASE_READINESS.md
