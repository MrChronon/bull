## v0.29.0.1 — Pack Library

**Stable · 11 October 2026 / Стабильный релиз · 11 октября 2026.**

Owner-authorized promotion to latest stable; release metadata/documentation only.
Published tag, ZIP/checksum and application/pack bytes are unchanged. / По решению
владельца — latest stable; tag, архив, checksum, программа и наборы не заменяются.

- Independent optional pack ZIPs, persistent user library, one exact version/subset per run.
- Setup: language → theme → packs/skip → full verification → connection/skip → launch/exit.
- Six Home sections; pack browsing inside testing; BULL Red / BULL Matrix and themed shortcuts.
- Author Workshop, complete private resume snapshots, recoverable Windows checkpoint writes.
- Basic/full diagnostics, honest empty-session state, bounded chat THINK fallback and owned-child cleanup.
- Four independent resource counters; language pack 1.0.1/scorer v2 and separate RU/EN reporting.
- Complete EN/RU repository documentation and publication handoff; no runtime changes in documentation preparation.

Независимые ZIP, Setup с выбором языка/темы, шесть разделов меню, мастерская,
resume-снимки, диагностика, обработка THINK, очистка своих процессов, отдельные
четыре датчика и RU/EN-результаты. Подготовка документации не меняет runtime.

Automated scope: 668 offline / 668 cp1251 / 18 essential startup checks.
Manual terminal, shutdown and live inference acceptance stays open. See
[current scope](Docs/RELEASE_READINESS.md), [full change record](Docs/CHANGELOG_v0.29.0.1.md)
and [release text](GITHUB_RELEASE_v0.29.0.1.md).
