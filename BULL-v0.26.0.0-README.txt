BULL v0.26.0.0 — Benchmarking & Usage of Local LLMs
=========================================

Релиз BULL RU Dialogue добавляет candidate pack bull_ru_dialogue@1.0.0:
10 параметризованных русскоязычных cases и раздельные semantic/structural scores.
Стабильный CHAT Core, recovery и runtime inference pipeline не изменены.

УСТАНОВКА
---------

  Install-BULL-v0.26.0.0.cmd

Основной клиент:

  BULL-v0.26.0.0.cmd

Benchmark Lab:

  BULL-Benchmark-Lab-v0.26.0.0.cmd

Agent Lab:

  BULL-Agent-Lab-v0.26.0.0.cmd

В релизе используются только launchers с именем BULL; старые алиасы удалены.
Подробности: Docs\MIGRATION_TO_BULL.md.

ПРОВЕРКА
--------

  Run-Tests.ps1
  Test-Public-Release.ps1 -AuditReleaseCandidatesOnly

Существующие benchmark prompts и scorers не изменены; новый scorer относится
только к RU Dialogue pack. Chats, Runtime, Benchmarks, Exports, Workspace, ключи
и client_debug.log нельзя публиковать.

Исходный код BULL распространяется по лицензии MIT. Полный текст: LICENSE.
Модели, движки и внешние benchmark packs сохраняют собственные лицензии.
